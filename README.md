[LoopLoopTech](www.looplooptech.com) 官网

## 技术栈

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4 + CSS Variables 双主题
- next-intl（`/zh`、`/en` 路由前缀国际化）
- next-themes（暗黑模式，跟随系统 + 手动切换）

## 本地开发

```bash
npm install
npm run dev      # http://localhost:3000
```

生产构建：

```bash
npm run build
npm run start
```
